# Nexora UI Foundation

You are a senior team consisting of a Product Designer, React Architect, UI Engineer, Motion Designer, and Frontend Lead.

Build Phase 1 of "Nexora", a premium futuristic AI desktop application.

Do NOT implement backend logic or AI features yet.

Focus exclusively on creating a production-quality UI and design system.

Requirements:

- React + TypeScript + Vite

- Tailwind CSS

- Framer Motion

- React Router

- shadcn/ui

- Lucide Icons

- Zustand

- Feature-based architecture

- Fully responsive

- Dark futuristic theme with subtle glassmorphism

- Animated AI orb with multiple visual states (idle, listening, thinking, speaking, offline)

- Sidebar, top command bar, dashboard, chat, memory, devices, files, automation, settings, and developer pages

- Command palette (Ctrl+K)

- Reusable component library

- Smooth transitions and micro-interactions throughout

- Widget cards for system information (mock data only)

- Notification centre and bottom status bar

- Clean, maintainable code with reusable components and scalable folder structure

The UI should feel comparable in polish to Raycast, Arc Browser, Cursor, and Linear, while maintaining its own identity. Avoid clutter and excessive neon effects. Prioritise usability, elegance, and premium visual quality.
